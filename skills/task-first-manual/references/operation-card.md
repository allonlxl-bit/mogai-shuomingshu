# 一页操作卡底稿

将下面的提示换成读者看到的具体内容。简单操作只留目标、步骤和完成判据。

**标题**　用动词描述做完的事，例如“把第二个方案改为 4 张标签”。

**先认对象**　写产品和适用版本，指向能看到型号、配置名或端口号的位置。如果有多套，直接告诉读者本页用哪套。

**开始前**　写从哪个页面、通电状态或机械位置开始。仅保留会影响本次操作的条件。

|图|找哪里、做什么|成功时看哪里|
|---|---|---|
|全景圈 ①|在什么面或页面，找到什么标记，执行什么动作|写实际字段、灯态或机械动作|
|局部圈 ②|进入下一状态后，按实物字样或菜单原文操作|给读者一个能继续往下做的判据|

**如果卡住**　指定症状 → 一项最有效的检查 → 返回哪个动作。会导致损坏、丢失或误控时写出停手点。

**最后验一次**　用用户实际要做的事做一次检查。只有确实发生过的操作才能标为已测。涉及设置保存时说明如何退出、再进入核对。

**出处**　产品版本、原厂章节/页码、图源；若用相近款参考图，紧跟该图写明差异。
