# 从容易返工的地方查起

|读者遇到的事|制作时怎么查|修到什么程度|
|---|---|---|
|“这个键在哪？”|盖住正文，只看图能否找到按键；再盖住图，看文字能否说清方向|给同朝向全景和局部圈位，正文保留按键印字和手势|
|“灯亮了，就成功了？”|查亮、闪、颜色和出现时机；确认截图是选项目、改数值还是运行状态|在具体步骤写明成功灯态，附一个失败时的去处|
|“上次保存的是 A，现在操作的是谁？”|区分当前选中、历史保存、在线连接和实际响应|先选对象，再写入，再用目标对象的独立反馈验证|
|“两台看起来一样，线该插哪？”|对照机身编号、针脚和插头视角；查电源正负及各端口已分配用途|图片、步骤与分配表逐项一致；仅有系列资料的地方留出实物核对点|
|“改一个设置，会不会把另一个功能也改掉？”|检查复用端口、前置校准、恢复默认、保存和重启的影响|保留必要前置步骤；给出受影响功能的复验办法|
|“从第二页开始看不懂”|挑一处读者能跟上的操作，比较每页是否漏掉找位置或确认结果|把已验证的图文组织方式应用到同类页，再检查导出成品|

修订时先定位事实变化。例如两个配置档交换了附件，列出相关章节里的旧名称、别称、图片和跨页引用。搜索文本后再看图，旧型号经常还印在图上。来源页可以保留真实的原厂基线，给使用者的操作页必须清楚标明当前分配。

首次读者走查三个问题：能否独立找到第一步？能否判断下一步什么时候做？看到异常时，知道在哪里停或怎么退回吗？把发现的缺口修在相应步骤旁。

## 裁图与成品走查

1. **先对原页。** 写下这张图要读者认出的一个证据，例如“成功框写着什么”或“开关右侧哪一格是指示灯”。记 PDF 物理页、原图朝向、局部范围和预期字样／外形。印刷页码与 PDF 页序可能有偏移，缩略图像素和 PDF 点也可能不同。把裁框画回同一原页，对照旁边的放大图。框中只有标题、说明文字、另一只按钮或隔壁的失败框，就重新取图。
2. **再按使用尺寸看。** 把正文临时遮住，照图指出应按的键，以及按完后要看的位置。有两张图并排或上下排列时，分别检查最小的一张。看不清印字就收紧裁框，失去方向感就另外保留小全景。成功与失败画面至少各读出一个能区分两者的特征。照片只能确认灯窗位置时，单独画注明“示意”的闪灯节奏或次数。
3. **走完每条路线。** 从速查页任选一套，再按其余每套重复。核对对象、菜单、按键、反馈所在部件，直至重启读回或终端动作。如果中途恢复了全行程、默认权限等临时状态，写明在哪一步恢复用户要求的限制，恢复后怎样验一次。共用页面上有分支时，确认读者不会误做另一套的步骤。
4. **最后看导出件。** 封面、索引和操作页各查自己承载的信息。页数、链接目标、缺图或文字溢出适合用程序检查；圈位含义、图文配对和操作时机仍需打开导出页核读。文字搜不到或提取乱码时，用可用的 PDF 渲染器打开原厂页面，按可见印字核读。网页预览打不开大手册时，从厂商手册目录下载同一版本，核对封面和页序。用错坐标或误配提示框后，从原图重裁，再检查最终文件中所有复用该图的位置。

### 可选的 PDF 裁图小工具

有 PDF 和裁框坐标时，可用 [proof_crop.py](../scripts/proof_crop.py) 生成制作端对照图，左侧为原页及裁框，右侧为实际放大的局部。它使用 Python、PyMuPDF 和 Pillow；已能用其他工具看原图时可直接对照。以下坐标仅演示调用格式。

```sh
python3 scripts/proof_crop.py manual.pdf --page 3 --box 40 90 250 180 --expect "Saved" --out crop-review.png
```

在技能目录下运行。页号从 1 起，坐标是去除页面旋转后的可见页坐标，单位为 PDF 点，原点在左上角。`--expect` 用于可选择的单行短语，每个短语应在裁框内完整命中一次。它只能检验文字落入框内。截图里的文字、引线终点、插针极性仍需看对照图；纯图页面省略该选项。命令报错时先核原页和范围，旧输出不可当作本次结果。
