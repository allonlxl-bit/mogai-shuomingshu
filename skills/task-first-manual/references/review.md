# 从容易返工的地方查起

|读者遇到的事|制作时怎么查|修到什么程度|
|---|---|---|
|“这个键在哪？”|盖住正文，只看图能否找到按键；再盖住图，看文字能否说清方向|给同朝向全景和局部圈位，正文保留按键印字和手势|
|“灯亮了，就成功了？”|查亮、闪、颜色和出现时机；确认截图是选项目、改数值还是运行状态|在具体步骤写明成功灯态，附一个失败时的去处|
|“上次保存的是 A，现在操作的是谁？”|区分当前选中、历史保存、在线连接和实际响应|先选对象，再写入，再用目标对象的独立反馈验证|
|“两台看起来一样，线该插哪？”|对照机身编号、针脚和插头视角；查电源正负及各端口已分配用途|图片、步骤与分配表逐项一致；仅有系列资料的地方留出实物核对点|
|“改一个设置，会不会把另一个功能也改掉？”|检查复用端口、前置校准、恢复默认、保存和重启的影响|保留必要前置步骤；给出受影响功能的复验办法|
|“从第二页开始看不懂”|挑一处读者能跟上的操作，比较每页是否漏掉找位置或确认结果|把已验证的图文组织方式应用到同类页，再检查导出成品|

修订时先定位事实变化。例如两个配置档交换了附件，列出相关章节里的旧名称、别称、图片和跨页引用。搜索文本后再看图，旧型号经常还印在图上。来源页可以保留真实的原厂基线，给使用者的操作页必须清楚标明当前分配。

首次读者走查三个问题：能否独立找到第一步？能否判断下一步什么时候做？看到异常时，知道在哪里停或怎么退回吗？把发现的缺口修在相应步骤旁。
