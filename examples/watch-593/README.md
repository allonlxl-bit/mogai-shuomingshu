# 把手表时间往前调一小时

**适用卡西欧 593 机芯。** 先看表背的机芯编号，确认是 593。假设现在显示 10:58，你希望改成 11:58。把表盘文字朝正，先找下面三个位置。字母是厂家图上的代号，表壳上可能印的是功能名。

```text
                 表盘朝向自己
        左上 L ● ┌─────────────┐
                 │   当前时间  │
        左下 C ● └─────────────┘ ● 右下 A
```

想对着实物认键，可以打开[厂家的单页实物图](https://support.casio.com/storage/en/support/download_files/en/009/DST_Setting/593_QuickOperationGuide.pdf)。从上往下四幅照片依次圈出 C、L、A、C。

|步骤|手怎么做|眼睛看哪里|
|---|---|---|
|① 进入调时|从平时看时间的画面开始，短按**左下 C**，每按一次先看一下表盘|走到**秒数闪动**时停手|
|② 选小时|短按一次**左上 L**|闪动位置从秒数移到**小时**。若还在闪秒数，先别按 A|
|③ 加一小时|确认小时正在闪，短按一次**右下 A**|例子中 **10** 变 **11**。看到目标小时就停|
|④ 回到看时间的画面|短按一次**左下 C**|小时停止闪动，当前时间显示新小时，秒数继续走|

这张卡按厂家 593 机芯夏令时调整单页核对。图中的按钮位置有原厂照片可对照，实表操作待读者按最后一行验证。
